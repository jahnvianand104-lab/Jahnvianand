# Jahnvi Anandakrishnan – personal website

A single-page static site. No build step, no database, no trackers.

- `index.html` – the whole site (content, styles, script)
- `_headers` – security headers applied by Cloudflare Pages
- `robots.txt` – lets search engines index the site

## Editing
Edit `index.html` and commit. Cloudflare Pages republishes automatically.
Search for `[contact email to be added]` and replace it with the real address before launch.

## Changing the colour code
Open `index.html` and find the block headed `COLOUR CODE` near the top.
Each line is one colour with a plain-English note. Replace the `#` value, commit, and the whole site follows.
Change nothing else in the file for a colour update.

## Hosting
Cloudflare Pages, connected to this repository. Build command: none. Output directory: `/`.
